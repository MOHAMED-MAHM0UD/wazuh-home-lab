# Wazuh Home Lab

A Wazuh home lab for SIEM monitoring, featuring Windows Sysmon integration, Slack alerting, Active Response, and File Integrity Monitoring (FIM).

## Overview

This project demonstrates the deployment and configuration of a Wazuh-based security monitoring environment in a home lab.

The lab focuses on endpoint monitoring, security alerting, automated response, and file integrity monitoring.

## Features

- Wazuh SIEM deployment
- Windows endpoint monitoring
- Sysmon integration
- Slack alerting
- Active Response
- File Integrity Monitoring (FIM)
